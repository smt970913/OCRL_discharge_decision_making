# Discharge Decision Making with Multiple Readmissions and Constraints


The repository contains code for our paper "Discharge with Multiple Readmissions and Constraints". This paper is completed by Maotong Sun (maotong.sun@tum.de) and Prof. Dr. Jingui Xie (jingui.xie@tum.de). If you need the original paper, please send a request to the author's email.
